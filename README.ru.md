## Что такое CR-Hopper?

CR-Hopper публикует компактный набор прокси-узлов, которые до публикации уже прошли предварительный отбор и подготовку к использованию.

Все исходные кандидаты прокси, обрабатываемые CR-Hopper, поступают из источников, уже публично доступных в Интернете. CR-Hopper не создаёт, не размещает и не эксплуатирует эти узлы; проект только собирает, отбирает, проверяет и повторно публикует прошедшее отбор подмножество в форматах, готовых для клиентов.

Публичная подписка может содержать разные протоколы, включая VLESS, Hysteria2 и Shadowsocks. Количество узлов и набор протоколов могут меняться после обновлений.

## Рекомендуемые клиенты

- **Hiddify:** используйте `CR-Hopper.txt`
- **Mihomo / Clash-совместимые клиенты:** используйте `CR-Hopper.yaml`

## Установка клиентов и подключение

- **Hiddify (TXT):** [Скачать](https://github.com/hiddify/hiddify-app/releases) · [Установка](https://hiddify.com/app/How-to-install-Hiddify-app/) · [Руководство](https://hiddify.com/app/How-to-use-Hiddify-app/). На главной странице нажмите **+ → Clipboard** (или **Manually**), добавьте TXT-ссылку выше и подключитесь.
- **Clash Mi (YAML):** [Скачать с сайта разработчика](https://clashmi.app/download) · [GitHub Releases](https://github.com/KaringX/clashmi/releases) · [Руководство](https://clashmi.app/guide/). Откройте **My Configurations → + → Add configuration link**, вставьте YAML-ссылку выше и включите подключение.

Оба клиента доступны для iOS, Android, macOS, Windows и Linux. Скачивайте приложения по ссылкам разработчиков; CR-Hopper не распространяет клиентские программы. [Пошаговая инструкция на сайте](https://agumuzi.github.io/crhopper/#setup).

## Примечания

- Публичные прокси-узлы могут перестать работать в любой момент. При проблемах с подключением сначала обновите подписку.
- Геолокация, которую показывает клиент, определяется самим клиентом и может отличаться от метки в имени узла.
- TXT и YAML содержат один и тот же опубликованный набор узлов в разных форматах.

## Внутренняя синхронизация Google Drive

**CR-Hopper Sync** — отдельная интеграция Google Drive только для сопровождающего проекта. Локальный сканер использует `rclone` для архивирования файлов проекта и рабочих журналов в собственном Drive владельца. Это **не вход через Google для публичных подписчиков**: использование TXT/YAML не требует разрешений Google, а ссылки подписок остаются прежними. Приватные данные сканера и учётные данные OAuth не размещаются в публичном репозитории.

[Политика конфиденциальности CR-Hopper Sync](https://agumuzi.github.io/crhopper/privacy.html) описывает доступ к данным, хранение, удаление и отзыв разрешений.

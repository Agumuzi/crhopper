## لینک‌های اشتراک

### Hiddify / اشتراک URI

لینک زیر را کپی کنید و در Hiddify یا هر کلاینت دیگری که از اشتراک URI پشتیبانی می‌کند، به‌عنوان پروفایل راه‌دور اضافه کنید.

```text
https://raw.githubusercontent.com/Agumuzi/crhopper/main/CR-Hopper.txt
```

### Mihomo / Clash YAML

لینک زیر را کپی کنید و در Mihomo یا کلاینت‌های سازگار با Clash به‌عنوان پروفایل YAML راه‌دور استفاده کنید.

```text
https://raw.githubusercontent.com/Agumuzi/crhopper/main/CR-Hopper.yaml
```

## CR-Hopper چیست؟

CR-Hopper مجموعه‌ای فشرده از نودهای پروکسی را منتشر می‌کند که پیش از انتشار، مرحله‌های انتخاب و آماده‌سازی برای استفاده را طی کرده‌اند.

اشتراک عمومی ممکن است شامل چند پروتکل مختلف، از جمله VLESS، Hysteria2 و Shadowsocks باشد. تعداد نودها و ترکیب پروتکل‌ها ممکن است در هر به‌روزرسانی تغییر کند.

## کلاینت‌های پیشنهادی

- **Hiddify:** از `CR-Hopper.txt` استفاده کنید.
- **Mihomo / کلاینت‌های سازگار با Clash:** از `CR-Hopper.yaml` استفاده کنید.

## نکات

- نودهای عمومی ممکن است هر زمان از دسترس خارج شوند؛ در صورت بروز مشکل اتصال، ابتدا اشتراک را به‌روزرسانی کنید.
- موقعیت جغرافیایی (Geo) که کلاینت نمایش می‌دهد توسط خود کلاینت تعیین می‌شود و ممکن است با برچسب داخل نام نود متفاوت باشد.
- فایل‌های TXT و YAML همان مجموعه نودهای منتشرشده را در دو قالب متفاوت ارائه می‌کنند.

## سلب مسئولیت

این مخزن داده‌های اشتراک عمومی پروکسی را برای آزمایش و استفاده شخصی از شبکه ارائه می‌کند. دسترس‌پذیری نودها، سرعت و موقعیت واقعی مسیر خروجی تضمین نمی‌شود.

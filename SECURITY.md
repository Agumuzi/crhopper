# Security Policy

## What this project does

CR-Hopper republishes selected **third-party public proxy nodes** as client-compatible feeds. The maintainers do **not** own or operate those servers. Node privacy, safety, uptime, location, and performance are not guaranteed.

This policy covers vulnerabilities in **project-maintained publication, website code, documentation, and maintained integration configuration**. It cannot guarantee or remediate weaknesses on independent third-party proxy servers.

## Report project vulnerabilities privately

Use [GitHub private vulnerability reporting](https://github.com/Agumuzi/crhopper/security/advisories/new) when it is enabled.

If private reporting is unavailable, [open an issue requesting a confidential contact method](https://github.com/Agumuzi/crhopper/issues/new) **without posting sensitive details**. Never disclose OAuth tokens, credentials, personal network identifiers, secrets or exploit instructions in public.

Provide a description of the affected component, potential impact, and a minimal reproduction without credentials or user data. Reports are handled as maintainer time permits; no response-time guarantee is offered.

## Report ordinary feed problems

For expired, unavailable, or malformed subscriptions, use [Issues](https://github.com/Agumuzi/crhopper/issues). Do not publish personal connection logs, private servers or credentials. Public upstream nodes may disappear without notice.
